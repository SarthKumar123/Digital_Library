# Digital Library

A full-stack Library Management System built using React.js, Spring Boot, and MySQL.

## Features

* User Registration and Login
* Admin Dashboard
* Book Management
* Borrow and Return Books
* Fine Management
* Mock Razorpay Payment Integration
* REST API Integration
* Responsive User Interface

## Technologies Used

### Frontend

* React.js
* Vite
* CSS
* Lucide React

### Backend

* Spring Boot
* Spring Data JPA
* REST APIs

### Database

* MySQL
